## How to Open the Project

1.  Install **Microsoft Power BI Desktop**.
2.  Clone or download this GitHub repository.
3.  Open `powerbi_project_.pbix` in Power BI Desktop.
4.  If Power BI prompts you to locate the source data, connect it to the
    correct file or data source.
5.  Refresh the data if needed, then explore the report pages and
    filters.

> If the report uses local file paths, credentials, gateways, or private
> data connections, another user may need to configure them before
> refreshing.
