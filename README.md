# Hospital Patient Care Analysis Dashboard

## Overview

The **Hospital Patient Care Analysis Dashboard** is an interactive data visualization project developed using Microsoft Power BI. It presents hospital-related information in a visual format to help users explore patient-care activity, monitor available performance indicators, and understand operational patterns.

The dashboard is designed to support data-driven discussions about hospital operations and patient care. The insights available depend on the fields and measures included in the report and its connected dataset.

## Problem Statement

Hospitals work with patient and operational data that can be difficult to interpret when viewed across separate records or tables. Without a consolidated view, it may be challenging to compare activity over time, monitor key indicators, and identify areas that may require further investigation.

This project addresses that challenge by bringing relevant hospital data into an interactive Power BI report. Charts, summary indicators, and report filters help users explore the data and review patterns from different perspectives.

## Project Objectives

- Present hospital and patient-care data in a clear, interactive dashboard.
- Make key indicators easier to review in one place.
- Explore patterns and comparisons supported by the available dataset.
- Help users investigate trends using report visuals and filters.
- Support operational analysis and informed resource-planning discussions.

## Tools and Technologies

- **Microsoft Power BI Desktop** — report development and data visualization.
- **Power BI report visuals** — charts, summaries, and interactive analysis.
- **Power Query and DAX** — used where included in the report for data preparation, calculations, or measures.

## Dashboard

The Power BI report contains six pages. Open the `.pbix` file in Microsoft Power BI Desktop to explore the pages, visuals, and available filters.

The report pages and metrics should be interpreted according to the data and calculations included in the file.

## Key Benefits

- Consolidates relevant hospital data into a single report.
- Makes it easier to explore patterns and compare available indicators.
- Provides an interactive way to review hospital-related information.
- Helps communicate data findings to technical and non-technical audiences.

## How to Open the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `powerbi_project_.pbix` in Power BI Desktop.
4. If prompted, configure the required data source or file path.
5. Refresh the report if necessary, then explore its pages and filters.

**Note:** Refreshing the report may require access to the original data source and any necessary credentials. The report may still open without refreshing, depending on how it was created.

## Privacy and Responsible Use

Hospital-related datasets may contain sensitive personal information. Do not publish identifiable patient information, medical record numbers, contact details, confidential hospital records, passwords, or access credentials.

This dashboard is intended for data exploration and operational analysis. It is not a substitute for professional medical judgment and should not be used as the sole basis for diagnosis or treatment decisions.

## Viewing on GitHub

GitHub displays this README and the repository files, but it does not render `.pbix` files as interactive dashboards. To interact with the report, download the Power BI file and open it in Power BI Desktop.
